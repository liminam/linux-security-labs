# 🐧 Linux Security Labs

**Laboratorios de Linux, Bash y seguridad informática**

Este repositorio documenta mi aprendizaje práctico de Linux y seguridad de sistemas durante mi formación en pentesting.

Soy estudiante de Informática en la UMSA y utilizo este espacio para desarrollar habilidades técnicas, documentar laboratorios y construir mi portafolio profesional de ciberseguridad.

## 🎯 Objetivos

- Dominar la terminal y la administración de Linux.
- Comprender permisos, usuarios y procesos.
- Aprender scripting Bash para automatizar tareas.
- Identificar configuraciones inseguras.
- Desarrollar una metodología de auditoría de sistemas.
- Documentar resultados y recomendaciones de seguridad.

## 🛠️ Herramientas

- Kali Linux
- Bash
- GNU/Linux
- OpenSSH
- Git y GitHub
- OverTheWire Bandit
- TryHackMe

## 📚 Temas de aprendizaje

| Tema | Descripción |
|---|---|
| Terminal | Navegación y administración de archivos |
| Búsquedas | Uso de `find`, `grep` y tuberías |
| Permisos | `chmod`, permisos octales y seguridad |
| Procesos | `ps`, `top`, `kill` y señales |
| SSH | Conexiones remotas y autenticación |
| Bash | Automatización mediante scripts |

## 🧪 Laboratorios y proyectos

Los proyectos se incorporarán conforme complete y apruebe sus evaluaciones prácticas.

**Próximos proyectos:**

- Auditoría básica de archivos y permisos.
- Investigación de procesos y registros.
- Automatización de revisiones de seguridad con Bash.
- Proyecto unificador de seguridad Linux.

Cada proyecto incluirá su objetivo, metodología, comandos utilizados, evidencias, resultados y recomendaciones.

## 🔐 Ética y seguridad

Todas las prácticas se realizan exclusivamente en entornos propios, máquinas de entrenamiento o sistemas donde exista autorización.

No se publicarán contraseñas, claves privadas, información sensible ni soluciones restringidas de plataformas de entrenamiento.

## 🚀 Objetivo profesional

Desarrollar habilidades prácticas en ciberseguridad ofensiva y construir un portafolio técnico que demuestre mis conocimientos mediante proyectos reproducibles y documentados.
